# reth v2.6.0 / OP develop bump Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move alethia-reth to reth v2.6.0 via OP develop's pins, rebuild proof-history on upstream v2 storage with OP's init + backfill jobs, and keep reth state masking off — with no consensus change.

**Architecture:** Every reth crate comes from `ethereum-optimism/reth@d9bd9875` so `reth-optimism-trie` (OP develop) shares one reth. Proof-history drops its own historical-anchor initializer: empty storage is filled by upstream `InitializationJob` at the on-disk tip, and window-only nodes then run upstream `BackfillJob` backward to `latest − window`. Legacy-v1 or half-initialized proof directories are deleted and rebuilt at open.

**Tech Stack:** Rust 1.95, reth v2.6.0 (OP fork), `reth-optimism-trie` (OP monorepo git dep), MDBX, cargo-nextest, just.

**Spec:** `docs/superpowers/specs/2026-10-18-reth-v2.6-op-develop-bump-design.md` (read it first; section numbers below refer to it).
